Core Features

为安全而生的
每一个功能

不是在普通聊天上贴一层加密，而是从协议层开始重新设计。每个字节离开设备之前就已完成加密。

端到端加密

Signal 协议 + 前向保密。服务器被攻破也无法解密历史消息。

毫秒级送达

WebSocket 长连接实时推送，多端同时在线消息无缝同步。

音视频通话

WebRTC 点对点直连，媒体流不经过服务器，无法被监听。

加密文件传输

任意格式、任意大小，传输全程加密，支持断点续传。

群组聊天

群消息同样端到端加密，群主可控成员权限与邀请链接。

六端全覆盖

Windows / macOS / Android / iOS / 鸿蒙 / 网页版，随你切换。
