Security Architecture
你的数据
只属于你

从设计之初就以安全为核心。不是事后加一层加密，而是整个系统围绕零信任架构构建。

01

Signal 协议加密

采用经过学术验证的 Signal 协议，前向保密 + 未来保密，每次会话生成独立密钥。

02

零知识服务器

服务器仅中转加密数据包，无法读取任何明文内容。即使被入侵也获取不到信息。

03

开源可审计

协议实现开源，任何人都可以审计代码。信任建立在代码上，不是承诺上。

04

无元数据留存

不记录聊天对象、不记录在线时间、不记录消息数量。服务器不留任何痕迹。
